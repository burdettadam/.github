# GitHub community defaults

This repository holds account-wide community files for [burdettadam](https://github.com/burdettadam). A funding link in `.github/FUNDING.yml` supplies the Sponsor button on repositories that do not define their own funding file.

The funding file is waiting for a verified PayPal.Me link. Once the link is ready, replace the commented example with `custom: "https://www.paypal.me/YourChosenName"` and commit the change to `main`.
